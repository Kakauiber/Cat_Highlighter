Obsidian 导出设置

按官方剪藏工具思路：先写入剪贴板，再调用 Obsidian App 把内容直接创建到指定仓库。

不知道怎么获取 Vault ID？
可直接填写仓库名称；如果需要获取 Vault ID，请按下面步骤操作：
  1. 打开 Obsidian 桌面版。
  2. 找到左下角的仓库切换器并切换至目标仓库。
  3. 右键点击目标仓库区域，在弹出菜单栏中点击“复制路径”。
官方文档说明：`vault` 参数既可以用仓库名称，也可以用 Vault ID；Vault ID 更稳定。

Notion 导出设置

通过 Notion 官方 API，在目标父页面下创建新的子页面。

不知道怎么配置 Notion？
  1. 打开 Notion 设置页，点击上方「连接」。
  2. 点击「开发或管理集成」，再点击「创建新集成」。
  3. 填写「集成名称」，并在「安装范围（Installation scope）」处选择目标父页面。
  4. 创建完成后，复制「API 集成密钥（Integration Token）」并粘贴到这里。
  5. 复制目标父页面链接，粘贴到「目标父页面链接 / ID（Page ID）」处即可。
测试会在目标父页面下创建一篇「划线猫 Notion 测试」子页面。正式导出前，建议先完成一次测试。

思源导出设置

按官方 API 直连思源本地服务，保存后可直接把高亮和笔记写入指定笔记本。

不知道怎么获取思源 API Token？
  1. 打开思源桌面版。
  2. 进入「设置」→「关于」。
  3. 复制页面中的 API Token，并粘贴到这里。
默认服务地址是 `http://127.0.0.1:6806`。测试或正式导出前，请先确认思源桌面版正在运行。

导出模板

自定义 Markdown 与笔记类导出的页面结构。

模板会逐页应用于 Markdown、墨问、Notion、Obsidian 和思源；HTML 与复制保持原样。

这是可选功能，保持默认模板即可正常导出。 导出时，花括号中的变量会自动替换为页面内容。你可以修改固定文字、Markdown 标题和章节顺序，也可以删除不需要的部分；请勿修改变量名称。点击下方变量按钮，可将变量插入光标位置。
插入变量

建议使用 section 变量：没有笔记或标注时会自动省略整个章节。多页面导出会按原顺序逐页套用模板。

查看变量说明与示例

可以修改什么

  • 修改普通文字、Markdown 标题符号和章节顺序。
  • 调整或删除变量，但不要修改花括号内的变量名称。
  • 暂不支持条件判断、循环、自定义颜色或复杂排版。
